# omniD

omniD gives an agent deterministic access to simulation solvers: their cases,
their shells and MPI, and the machine they run on, through one command,
`omnidriver`, whose answers and refusals are JSON. The solvers today are
cardiacFOAM and cardiacSubstrateFOAM (OpenFOAM), openCARP and TorchCor.

Start with [`AGENTS.md`](AGENTS.md): it routes an agent, or a person, to the
documents for the task.
